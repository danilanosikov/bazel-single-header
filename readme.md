# okular system
библиотека для работы с операционной системой
запаковывает системные вызовы в предсказуемые обёртки

# настройка 
```sh
# настройка clangd
bazel run //:clangd

# сборка всего
bazel build ...

# отчистка сборки
bazel clean
```


# абстракция подсистем:
[ ] операции с памятю
[ ] операции с файловой системой
[ ] операции вызова отрисовочной поверхности
[ ] операции низкоуровневой работы со звуком
[ ] операции низкоуровневого ввода-вывода


# правила

- не использовать malloc и др обёртки - обращаться к подсистемам операцонной системы напрямую, те если используетя wayland - обращаться напрямую к композитору, а не через wlroots, если необходимо выделить память - выделять её напрямую через ядро, минуя обёртки по типу malloc, calloc и др
